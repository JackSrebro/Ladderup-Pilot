# Ladder Up Pilot

Career roadmap for firefighters, EMTs and paramedics in Will County and the southwest Chicago suburbs.

- `index.html` is the page.
- `data.js` holds every listing (classes, departments, jobs, funding, continuing ed, test dates). The weekly refresh updates this file.

Static site, no build step. Netlify publishes every change to this repository automatically.

Live site: https://ladderup-pilot.netlify.app
